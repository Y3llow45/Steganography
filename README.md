## Description

This application hides UTF-8 text inside PNG images using subtle red-channel pixel changes. The GUI and CLI support hiding a message and recovering it by comparing the encoded image with the **original** image. It is an educational steganography project, **not encryption**: do not rely on it to protect sensitive data.

## Features
1. Hide and extract UTF-8 text (including non-ASCII characters) inside lossless PNG files.
2. Desktop GUI using PySide6 and a command-line interface.
3. Length-prefixed message format: no fragile zero-bit terminator.
4. Detect invalid message headers, insufficient image capacity, mismatched dimensions, and existing output filenames.
5. Customizable GUI using CSS.

**Compatibility:** Images generated by the old encoder are not supported by the updated decoder. The application requires **both** the original PNG and the encoded PNG to recover a message. Convert neither image to a lossy format such as JPEG.

## Applications
1. **Digital watermarking**: Steganography can be used to embed a digital watermark within an image or video, allowing copyright owners to **protect their intellectual property from unauthorized use or distribution**.
2. **Information hiding**: Demonstrates how data can be concealed in images. Hiding is not confidentiality; use proper encryption when secrecy is required.
3. **Covert communication**: Steganography can be used to hide communication within **social media posts, images, or videos**.This can be useful for covert communication in situations where traditional methods of communication may be **monitored or censored**.
4. **Digital forensics**: Steganography can be used in digital forensics investigations to **detect hidden messages or files** that may be relevant to a case.

# IMPORTANT notes
1. Avoid using images that have a uniform color tone or pattern. If the pixels in the image are too similar, the hidden information may be detected by others.
2. To ensure better privacy, use images captured with your own phone or camera instead of those sourced from the internet. Online images can be quickly traced using AI technologies.
3. For maximum security, use different images for each message. Make sure these images are original, captured by you, and have not been uploaded anywhere, not even on your backup cloud. It's best to use images captured with your own camera insted of your phone unless you have taken serous privacy measures.

## Installation
```bash
pip install -r requirements.txt
```

Run the desktop UI:
```bash
python pyqt.py
```

Or use the CLI:
```bash
python hideRead.py -m H -oimg original.png -msg "Hello София!" -out hidden.png
python hideRead.py -m R -oimg original.png -simg img/hidden.png -bm y
```

Output filenames without directories are saved to `img/`; explicit paths are respected.
Run regression tests with `python -m unittest discover -s tests`.
